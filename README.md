# OpenIVM Spark Extension

> Big things coming soon 😉

DBSP/OpenIVM backed incremental view maintenance for Spark 3.5 / Delta 3.2 and Spark
4.1 / Delta 4.2.

Development and CI use a prebuilt, content-addressed devcontainer with Nx as
the shared command surface. See:

- [Contributing](CONTRIBUTING.md) for the developer setup.
- [Headless devcontainer operations](docs/devcontainer/headless-operations.md)
  for Docker-only WSL automation.
- [The extension README](spark-ext/README.md) for build, test, publication, and
  activation details.
